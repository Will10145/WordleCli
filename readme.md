## Connect

### Termius

<a href="https://account.termius.com/host-sharing#ip=wordle.willcodes.tech&port=2222&label=Wordle&username=wordle&os=debian">

</a>

### Any SSH Client

```bash
ssh -p 2222 wordle@wordle.willcodes.tech
```

> [!TIP]
> A password is not required. For leaderboard saving your public key will be remembered (But not shared), or as a fallback your IP will be used (Not shared). Both of these are NOT required. Also remember the port and username.
